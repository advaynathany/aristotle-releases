# Aristotle releases

Downloads and updates for **Aristotle**, a Mac app for thinking a decision through with the people
you trust, from their own words. It runs on your Mac with your own Claude subscription.

**Download:** [Aristotle.dmg](https://github.com/advaynathany/aristotle-releases/releases/latest/download/Aristotle.dmg)
(Apple silicon Macs). Open it, drag Aristotle to Applications, and see *Read me first* inside.

The app updates itself from this repo. `channels/stable.json` and `channels/beta.json` name the
current release of each channel, and `files/` holds every release. Each release is signed, and the
app installs nothing without a valid signature. Choose Stable or Beta in the app: click the version
number at the bottom of the sidebar.
